Contact

Email quickpolymath@gmail.com with questions or bug reports. Include device model, OS version, app version, steps, expected result, and what happened.

Troubleshooting chat

  • “Chat is unavailable” — this build is not connected to Halo’s agent service. There is no Settings field for an API key by design.
  • Slow or failed replies — check your network; try again if rate-limited.
  • Shell language — Settings → Interface language (廣東話 / English / Follow system). The agent still replies in Hong Kong Cantonese.

Privacy & data

  • Conversations stay on your device until you delete them.
  • Settings → Delete all data wipes local conversations.
  • Full policy: Privacy Policy.

What’s in v1

Text chat is available. Voice and vision modes are not included in this release.
