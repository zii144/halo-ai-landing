Data flow

Plain-language path for users and App Store / Play reviewers.

You type a message
        │
        ▼
On-device app (Halo AI)
  • Saves the turn locally (SQLite / web snapshot)
  • Does NOT hold an Anthropic API key
        │
        │  HTTPS POST /v1/turns (streaming)
        ▼
Agent proxy (developer-operated)
  • Holds the Anthropic key server-side
  • Forwards the turn to Claude
        │
        ▼
Claude model reply (streamed back)
        │
        ▼
On-device app
  • Shows the reply
  • Saves it in local conversation history

What never leaves by default: full conversation archives as a bulk export, analytics of chat content, or any user-entered API key (there is none).

Voice / vision: not shipping in v1; those routes are flag-gated stubs.
